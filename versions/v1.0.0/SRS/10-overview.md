# SRS Overview

Titeny mengelola AI insight platform dengan prediksi harga 12 komoditas × 8 pasar dan 11 event idempoten.

Dokumen SRS ini menjadi cetak biru formal untuk pengembang dan QA. TDD wajib menurunkan test dari requirement di sini.

## Batasan

SRS tidak memuat kode produksi; hanya requirement formal dan QA gate.
